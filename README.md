# Mohammad & Ayesha — Interactive Royal Nikkah Invitation

An ultra-luxury, responsive, animated wedding website created for **Mohammad & Ayesha**. Features a 3D Wax Seal Envelope opening experience, celebratory confetti bursts, interactive "Scratch to Reveal" date cards, formal royal Islamic arch invitation card, wedding timeline, live countdown to Qubool Hai, venue details with Google Maps & calendar integration, and interactive RSVP & guestbook.

## Features Included

- **3D Wax Seal Envelope Entrance**: Interactive wax seal with "M A" monogram. Tap/click to break seal and open the envelope with 3D folding flaps and confetti burst.
- **Hero Section**: Majestic palace arch background with Mohammad & Ayesha in royal wedding couture.
- **Celebration Confetti**: Music removed and replaced with interactive confetti bursts upon envelope open, scratch reveal, and floating shower button.
- **The Date (Scratch to Reveal)**: 3 interactive gold-foil scratch cards for Day (`10`), Month (`January`), and Year (`2027`) supporting mouse and touch swiping.
- **Formal Nikkah Invitation**: Gilded Arabesque arch silhouette, Bismillah calligraphy, and heartfelt invitation from both families.
- **Wedding Timeline**: 5 glowing milestone steps from welcome drinks to celebrations & send-off.
- **Countdown Timer**: Real-time ticker counting down to January 10, 2027.
- **Venue & Location**: Four Seasons Resort Jumeirah, Dana Ballroom, Dubai with direct Google Maps link and .ics calendar download.
- **Colour Code Removed**: Per request, the dress code / colour code section has been removed completely.
- **RSVP & Wishes Wall**: Built-in guest response form and live prayer/wishes wall.

## Run on Windows

1. Double-click `START_NIKAH.bat` (or run `node local-server.js` in terminal).
2. Open **http://localhost:3000** in your browser.
3. You can also open `public/index.html` directly in any web browser without running a server!
